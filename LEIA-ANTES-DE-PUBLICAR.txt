GESTÃO DE RESULTADOS — PLATAFORMA INDEPENDENTE

Esta é uma cópia separada do ecossistema original. O projeto anterior não foi alterado.

O QUE JÁ ESTÁ FUNCIONANDO NESTA PRIMEIRA BASE
- Entrada própria da plataforma.
- Validação pela mesma nuvem de autorizações do ecossistema FS.
- Reconhecimento automático quando a sessão válida vier do ecossistema principal e os dois sites estiverem no mesmo domínio.
- Solicitação dos dados autorizados quando o link for aberto diretamente ou em outro domínio.
- Controle de dispositivo já utilizado pela autorização atual.
- Gestão de Resultados preservada com cálculos, metas, vendedores, histórico, BI e sincronização em nuvem.
- Instalação como aplicativo PWA no celular ou computador.
- Interface responsiva para mobile, tablet e desktop.

PUBLICAÇÃO
1. Crie um repositório/pasta independente para esta plataforma.
2. Envie todos os arquivos desta pasta, mantendo os nomes.
3. Abra primeiro index.html. A página resultados.html permanece protegida pelo access-guard.js.
4. Depois de obter o link definitivo, atualize o card Gestão de Resultados do ecossistema principal.

IMPORTANTE PARA O PILOTO
- Esta versão inicial mantém a base gerencial já sincronizada da Loja 28.
- Ainda não compartilhe o acesso com vendedores: a separação por perfil, filial e vendedor será a próxima etapa.
- A sincronização atual usa uma base gerencial compartilhada. A evolução para várias filiais exigirá particionamento dos dados na nuvem.
